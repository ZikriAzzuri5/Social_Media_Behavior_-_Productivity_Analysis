# Social Media Behavior & Productivity Analysis

Analisis hubungan antara perilaku penggunaan media sosial dengan produktivitas, menggunakan dataset sintetis dari Kaggle (300 partisipan).

Dataset: [Social Media, Dopamine, and Productivity Dataset](https://www.kaggle.com/datasets/manaswinsripatnala/social-media-dopamine-and-productivity-dataset)
